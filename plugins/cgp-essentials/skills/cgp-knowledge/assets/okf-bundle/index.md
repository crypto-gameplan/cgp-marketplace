# About this bundle

Project knowledge in Open Knowledge Format v0.2: one concept per markdown file, with YAML frontmatter.
Start here and follow the indexes. Prefer human-reviewed concepts; check `status` and `stale_after` before relying on one.

# Types

* `Playbook` - steps for a recurring task
* `Decision` - a decision, its reasons and when to revisit it
* `System` - a service, tool or account and how it is used
